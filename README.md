# Namer

フォルダ内のファイルを一括リネームする GUI ツールです。

## できること

- **共通接頭語の除去**（自動検出、または手動指定）
- **接頭語の追加**
- **拡張子直前への番号付け**（開始番号・桁数・区切り文字・前後位置）
- **大文字 / 小文字 / Title Case への統一**
- 実行前の **プレビュー** と衝突チェック

## ダブルクリックで起動（おすすめ）

1. `build_exe.bat` をダブルクリックしてビルドする  
   （または `uv run pyinstaller --noconfirm namer.spec`）
2. できた **`dist\Namer.exe`** をダブルクリックで起動

`Namer.exe` は単体で動くので、デスクトップなどにコピーして使えます。

## 開発時の起動

```bash
uv run python main.py
```

## 操作の流れ

1. 「参照…」で対象フォルダを選ぶ
2. オプションを設定する（プレビューは自動更新）
3. 問題なければ「リネーム実行」
